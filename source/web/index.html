Как подключить аккаунт через cookies
  1. Для более устойчивого входа открой отдельное приватное окно браузера, затем YouTube Music и войди в нужный аккаунт. Разреши расширению работу в приватном окне.
  2. Установи расширение: cookies.txt для Firefox или Get cookies.txt LOCALLY для Chromium.
  3. В той же вкладке приватного окна открой youtube.com/robots.txt. Экспортируй cookies в формате Netscape cookies.txt. Выбери Export, а не Export All Cookies.
  4. Закрой приватное окно без выхода из аккаунта. Выбери файл ниже, нажми «Показать аккаунты» и подключи нужный профиль.

После загрузки выбери аккаунт по имени. Cookies дают доступ к сессии — экспортированный файл можно удалить после подключения.

У каждого профиля свои лайки и плейлисты. Выбери тот, которым пользуешься в YouTube Music.
