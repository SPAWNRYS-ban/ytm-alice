# ytm-alice 0.7.0

Первый публичный выпуск для Яндекс Станции Лайт первого поколения
(YNDX-00025, yandexmicro) с root-доступом и YAM v2.

- Автономное воспроизведение YouTube Music, поиск и очередь.
- Веб-панель по HTTP: управление, лайки, личные плейлисты и вход через cookies YouTube.
- Голосовые команды штатной Алисы, фраза «Включаю» и физическая кнопка паузы.
- Единый пакет со встроенным медиаслоем bt-proxy.
- Дополнительный CLI для Linux/macOS с интерактивной панелью и HTTP-подключением.
- Сборка из открытых исходников, CI и контрольные суммы релиза.

Для установки скачайте `ytm-alice-station.tar.gz`, распакуйте и запустите
`python3 ytm-alice-station/install.py ytm-alice-station/*.yampkg --host alice`
на компьютере с настроенным root SSH-доступом. Пошаговая инструкция — в README.
Файлы `.yampkg` можно установить вручную через YAM v2.

`install-client.sh` устанавливает необязательный клиент на компьютер;
`ytm-alice-cli.py` — сам клиент. `SHA256SUMS` содержит контрольные суммы всех файлов.

Ограничения: другие модели не проверены, личные списки ограничены первой
страницей (до 50 элементов), сессии YouTube требуют повторного импорта после
истечения. Вход в аккаунт не обещает доступ к закрытым/возрастным аудиопотокам.
Панель без пароля предназначена для доверенной локальной сети.
Речь распознаётся штатной облачной Алисой. Spotify и AirPlay в этот пакет не входят.
