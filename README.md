## Установка

Скачайте `.yampkg` из [последнего релиза](https://github.com/SPAWNRYS-ban/ytm-alice/releases/latest) и установите через [YAM v2](https://github.com/nyakokitsu/yam):

```sh
yam install --yes ytm-alice-0.7.0-yandexmicro.yampkg
/data/yam/bin/ytm-alice daemon install
```
