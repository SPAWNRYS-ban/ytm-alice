# Участие в проекте

## Сообщить об ошибке

Поищите похожую задачу в Issues, затем выберите шаблон «Ошибка».
Укажите версию ytm-alice и YAM, модель Станции, способ управления (голос,
веб или CLI), точные шаги и ожидаемый/фактический результат.
Для сбоя воспроизведения приложите название или публичную ссылку на трек
и время сбоя. Ошибки с одним названием трека труднее воспроизвести.

На Станции полезны:

```sh
ytm-alice --version
yam --version
ytm-alice --json status
ytm-alice web status
tail -n 80 /tmp/ytm-alice.log
tail -n 80 /tmp/ytm-alice-player.log
```

Перед публикацией просмотрите вывод. Удалите cookies, заголовки Authorization,
подписанные URL потоков, адреса электронной почты и личные данные.
**Не прикладывайте cookies.txt, youtube-session.json, браузерные базы, SSH-ключи
или полный архив /data.** Для отчёта достаточно относящегося к сбою фрагмента.

## Предложить изменение

Выберите шаблон «Предложение». Опишите задачу пользователя, желаемое поведение
и пример использования. Если есть обходной путь или ограничения устройства,
добавьте их. Вопросы по установке можно оставить в шаблоне «Вопрос».

## Изменить код

Сборка и проверки описаны в [BUILDING.md](BUILDING.md).
Для PR кратко опишите проблему, изменение поведения и проверки. Изменение
сетевого обмена, медиаслоя или установки должно включать проверку ошибок,
очистки ресурсов и сохранности сессии/очереди. Для небольшого текста или
стилей достаточно подходящей ручной проверки.

Ветки, артефакты и логи не должны содержать реальные аккаунты или секреты.
Сторонние компоненты сохраняют собственные лицензии и авторство.
