# ytm-alice 0.7.2-hotfix

Исправлена ошибка «неизвестный адрес колонки» при открытии веб-панели по IP.

Сервис раньше запоминал IP-адреса только при запуске. Если Wi-Fi получал адрес
позже или DHCP выдавал новый адрес, панель отвечала HTTP 403. Теперь она проверяет
текущий адрес подключения и актуальные адреса интерфейсов; перезапуск после
смены IP больше не нужен.

- Исправление относится к стабильной ветке и работает без Luna.
- Добавлены проверки смены IPv4/IPv6 и сохранения ограничений Host/Origin.
- Аккаунт YouTube и очередь при обновлении сохраняются.

## Обновление

Скачайте `.yampkg` для своей модели из вложений и выполните на Станции:

```sh
/data/yam/bin/ytm-alice daemon stop
yam install --yes ytm-alice-0.7.2-hotfix-yandexmicro.yampkg
/data/yam/bin/ytm-alice daemon install
```

Для Мини 2 используйте пакет `yandexmini_2`.
[Инструкция](https://github.com/SPAWNRYS-ban/ytm-alice#readme).
