# ytm-alice 0.7.6

Музыкальные запросы Алисы через YouTube Music, стабильное соединение с aliced
и исправления ошибок потока. Общий медиаслой ARM32/ARM64 и все 10 платформенных
пакетов для 12 Linux-моделей сохранены.

## Изменения

- [PR #20](https://github.com/SPAWNRYS-ban/ytm-alice/pull/20): соединение
  с aliced остаётся открытым в тишине. Убраны переподключения каждые две секунды,
  которые сопровождались ростом задержки ответов Алисы.
- [PR #21](https://github.com/SPAWNRYS-ban/ytm-alice/pull/21): опция
  `youtube_only` («Вся музыка через YouTube»), поиск по музыкальному ответу Алисы,
  альбомы и жанровые плейлисты, сверка с произнесёнными словами, удаление дублей
  аудио/клипов из радио и рекомендаций. По умолчанию опция выключена.
- В запрос YouTube Music передаётся signatureTimestamp декодера. После 403
  сбрасываются программа, timestamp и кеш страницы выбора плеера, чтобы следующий
  запрос действительно загрузил актуальную версию. Сетевые сбои этот кеш сохраняют.
- Явно распознанные команды отменяют штатный ответ уже на окончательном ASR;
  события ASR и BUSY одного запроса не выполняют команду дважды. Повторная команда
  с новым request ID обрабатывается сразу.
- Недоступные по аккаунту, возрасту или региону треки пропускаются в пределах
  текущей очереди. Если недоступны все оставшиеся треки, очередь заканчивается
  ошибкой; голосовое сообщение не повторяется на каждом промежуточном пропуске.
- В `announce_text` доступны `{artist}` и `{title}`, например
  `Включаю {artist}. {title}`. Старые настройки сохраняют поведение.
- Исполнитель альбома подставляется из заголовка, если отсутствует в строках треков.

## Проверки и ограничения

Go с проверкой гонок и vet, Python CLI/HTTP, JavaScript панели, Rust медиаслоя
и сборка пакетов проверяются CI. Аппаратные проверки автора PR выполнены на
Мини 2; это не подтверждает физическую работу всех моделей.
[Матрица стенда 0.7.5](KUYASE-MATRIX.md) остаётся историческим результатом:
новые облачные голосовые сценарии не проверяются эмулятором.

Часть [#19](https://github.com/SPAWNRYS-ban/ytm-alice/issues/19) и
[#22](https://github.com/SPAWNRYS-ban/ytm-alice/issues/22) остаётся открытой:
громкость будильника, полное подавление предложений подписки на всех прошивках,
удаление записанной тишины, fade-out/crossfade и расширенные средства диагностики.
Отмена ответа зависит от прошивки и момента получения события облака;
`youtube_only` не гарантирует отсутствие краткого звучания штатного плеера.
Сырые ответы с cookies, токенами и подписанными URL в журналы не выводятся.

## Обновление

Скачайте пакет своей платформы из релиза. Аккаунт, очередь и настройки сохраняются.

```sh
/data/yam/bin/ytm-alice daemon stop
yam install --yes ytm-alice-0.7.6-yandexmicro.yampkg
/data/yam/bin/ytm-alice daemon install
```

Для Мини 2 используйте `yandexmini_2`; для остальных моделей см.
[инструкцию сборки](BUILDING.md) и [матрицу](KUYASE-MATRIX.md).
