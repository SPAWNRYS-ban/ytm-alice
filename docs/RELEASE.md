# ytm-alice 0.7.5

Вход по коду YouTube TV, поиск неофициальных треков и общая сборка медиаслоя
для 12 Linux-моделей Станций. Luna для работы не требуется.

## Что нового

- **Вход по коду:** один раз подтвердите код на странице Google. Refresh-токен
  позволяет автоматически обновлять access-токен; импорт cookies остаётся доступен.
  В панели — «Войти по коду», на Станции — `ytm-alice login tv`, на ПК —
  `ytm-alice login --tv`. Лайки, плейлисты и радио работают через клиент YouTube TV.
  [PR #17](https://github.com/SPAWNRYS-ban/ytm-alice/pull/17),
  [issue #16](https://github.com/SPAWNRYS-ban/ytm-alice/issues/16).
- **Поиск видео:** если среди музыкальных треков нет релевантного результата,
  голосовой запрос ищет обычные видео YouTube. Учитываются название и исполнитель,
  включая кириллическую запись имени. Например, `Yowai The Maid` находит `Chasm`,
  а не похожее имя `Yabai The Maid`. При отсутствии результата текущая музыка
  продолжает играть. [Issue #14](https://github.com/SPAWNRYS-ban/ytm-alice/issues/14).
- **Собственный домен панели:** список `web_hosts` настраивается через панель
  или CLI. Прокси может сохранять Host и завершать HTTPS; проверки Origin и
  защита от посторонних Host сохраняются.
  [Issue #15](https://github.com/SPAWNRYS-ban/ytm-alice/issues/15).
- **Исправлена подсветка:** при отключённой подсветке приложение временно
  отсоединяет LED-trigger прошивки и сохраняет владение кольцом между треками
  и во время буферизации. При обращении к Алисе, паузе, остановке и завершении
  демона исходный trigger восстанавливается.
  [Issue #13](https://github.com/SPAWNRYS-ban/ytm-alice/issues/13).
- HTTPS читает оба штатных расположения CA-бандла Quasar, включая прошивки
  Станции 3; проверка сертификатов остаётся включена.
- **Общий медиаслой ARM32/ARM64:** пакет содержит оба плеера и выбирает ABI
  по библиотеке прошивки. Исправлен запуск на Мини 3 Про и Станции 3.
  Все 10 платформенных пакетов YAM используют одинаковые бинарники и входят
  в общий архив `ytm-alice-station.tar.gz`. Раздельные `.yampkg` нужны из-за
  проверки target в YAM v2.

## Модели и проверки

Стенд kuyase покрывает Лайт 1, Мини 1, обе Мини 2, Мини 3, Мини 3 Про,
обе Лайт 2, Миди, Стрит, Станцию 2 и Станцию 3. Проверяются запуск, CLI/HTTP,
локальный AAC через ALSA, статический декодер JavaScript и сохранность настроек
после перезапуска. [Матрица](KUYASE-MATRIX.md).

Физические проверки нового релиза на всех моделях не выполнялись. Облачные
голосовые команды, Bluetooth/MPRIS и слышимость динамика требуют устройств.
TTS в заглушке kuyase возвращает тайм-аут подтверждения завершения; эта проверка
не считается успешной. Управление I2C-кольцом Мини 1 пока не реализовано.
Android/YaOS-модели не поддерживаются.

У клиента TV нет музыкальной главной YTM: рекомендации строятся как радио от
последнего лайка. Для треков, требующих входа (включая часть 18+), можно добавить
cookies к TV-входу; их истечение не отключает личную библиотеку TV.
Доступ Google можно отозвать, а изменения YouTube могут потребовать нового входа.

## Установка и обновление

Скачайте `.yampkg` своей платформы. Аккаунт, очередь и настройки сохраняются.

```sh
/data/yam/bin/ytm-alice daemon stop
yam install --yes ytm-alice-0.7.5-yandexmicro.yampkg
/data/yam/bin/ytm-alice daemon install
```

Для Мини 2 обеих версий используйте `yandexmini_2`, для обеих Лайт 2 — `plum`,
для Станции 2 — `yandexstation_2`. Остальные платформы: `yandexmini`, `bergamot`,
`cucumber`, `pickle`, `mango`, `orion`. Адрес панели: `ytm-alice web status`.

[Изменения с 0.7.4](https://github.com/SPAWNRYS-ban/ytm-alice/compare/v0.7.4...v0.7.5)
