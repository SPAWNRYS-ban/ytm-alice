# ytm-alice 0.7.4

Стабильный релиз с трансляцией из YouTube Music, перемоткой, полными плейлистами
и постоянными настройками. Luna для работы не требуется.

## Что нового

- **Трансляция с телефона:** Станция появляется в списке устройств приложения
  YouTube Music; доступны очередь, пауза, переключение треков и громкость.
  [PR #10](https://github.com/SPAWNRYS-ban/ytm-alice/pull/10).
- **Меньше запросов к YouTube:** общий клиент и кеш страниц. После HTTP 429
  включается пауза от 2 до 30 минут с понятным сообщением; уже полученные ссылки
  продолжают работать. **Перемотка** больше не переключает трек и не ждёт
  в тишине: `ytm-alice seek 60` работает на Станции и в CLI-клиенте.
  Позиция округляется до начала ближайшего аудиофрагмента.
  [PR #11](https://github.com/SPAWNRYS-ban/ytm-alice/pull/11).
- **Настройки сохраняются после перезапуска:** порт панели, радио,
  перемешивание, фраза «Включаю», уведомления об ошибках и подсветка кольца.
  Свои голосовые фразы настраиваются отдельно во вкладке «Команды».
- **Полные плейлисты, лайки и библиотека:** исправлены продолжения списков,
  убрано ограничение первой страницей. Добавлены персональные рекомендации,
  перемешивание с сохранением текущего трека и радио после конца очереди.
- **Исправлено получение аудиопотоков:** при подключённом аккаунте сначала
  используется сессия YouTube Music, в том числе для explicit-треков. Современный
  декодер подписей работает на Станции без Node.js и Python.
  Для возрастных ограничений нужна действующая сессия с подтверждённым возрастом.
  Эти изменения и настройки: [PR #12](https://github.com/SPAWNRYS-ban/ytm-alice/pull/12).
- В релизе готовы YAM-пакеты для `yandexmicro` и `yandexmini_2`, CLI-клиент,
  исходники и контрольные суммы SHA-256.

## Связанные issue

  Существующие установки сохраняют свой порт, включая `80`.

- [#6 — плейлисты, радио и настройки](https://github.com/SPAWNRYS-ban/ytm-alice/issues/6):
  реализованы полная загрузка списков, перемешивание, радио и дополнительные настройки.

## Установка и обновление

Скачайте `.yampkg` для своей модели из вложений. На Станции с YAM v2:

```sh
/data/yam/bin/ytm-alice daemon stop  # при обновлении
yam install --yes ytm-alice-0.7.4-yandexmicro.yampkg
/data/yam/bin/ytm-alice daemon install
```

Для Мини 2 с часами используйте `ytm-alice-0.7.4-yandexmini_2.yampkg`.
Аккаунт, настройки и очередь сохраняются. Адрес панели: `ytm-alice web status`.
Проверены Лайт 1 и Мини 2 с часами; работа остальных моделей пока не подтверждена.
