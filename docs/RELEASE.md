# ytm-alice 0.7.7

Перемотка голосом и в веб-панели, исправление поиска по названиям с `%`
и автозапуска на прошивках Мини 1 без BlueZ.

## Изменения

- В веб-панели можно нажать на полосу прогресса, перетащить ползунок или
  сдвинуть позицию на 30 секунд. При перетаскивании колонка получает команду
  после отпускания ползунка. Голосовые команды поддерживают точную позицию
  («Алиса, перемотай на 1:30») и смещение («Алиса, перемотай назад на 30 секунд»).
  Перемотка работает с MP4-потоками, у которых есть индекс фрагментов.
  [PR #32](https://github.com/SPAWNRYS-ban/ytm-alice/pull/32)
- Запросы вроде «100%» распознаются как текст поиска, даже если их нельзя
  разобрать как URL. Раньше это могло обрушить демон при голосовом запросе
  или поиске из панели. [PR #33](https://github.com/SPAWNRYS-ban/ytm-alice/pull/33)
  · [Issue #31](https://github.com/SPAWNRYS-ban/ytm-alice/issues/31)
- `daemon install` устанавливает автозапуск и при ошибке медиаслоя. На прошивке
  Мини 1 без BlueZ службы медиаслоя пропускаются. Bluetooth-управление через MPRIS
  на этой прошивке недоступно.
  [PR #34](https://github.com/SPAWNRYS-ban/ytm-alice/pull/34)
  · [Issue #30](https://github.com/SPAWNRYS-ban/ytm-alice/issues/30)

Перемотку на Лайт 1 проверил автор PR. Изменение автозапуска проверено тестами
и в окружении без BlueZ. Подтверждение на физической Мини 1 ещё требуется.

## Обновление

Выберите пакет для своей платформы. При обновлении сохраняются аккаунт, очередь
и настройки. Ниже пример для Лайт 1.

```sh
/data/yam/bin/ytm-alice daemon stop
yam install --yes ytm-alice-0.7.7-yandexmicro.yampkg
/data/yam/bin/ytm-alice daemon install
```

Для Мини 1 используйте пакет `yandexmini`, для Мини 2 — `yandexmini_2`.
Другие платформы перечислены в [матрице](KUYASE-MATRIX.md).
