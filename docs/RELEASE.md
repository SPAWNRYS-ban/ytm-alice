# ytm-alice 0.7.0

YouTube Music для Яндекс Станций.

> [!WARNING]
> Тестирование проводилось только на **Яндекс Станции Лайт 1 (YNDX-00025)**.
> Работа на других моделях пока не проверена.

Установите `.yampkg` через YAM v2:

```sh
yam install --yes ytm-alice-0.7.0-yandexmicro.yampkg
/data/yam/bin/ytm-alice daemon install
```

## Отдельные бинарники

Помимо `.yampkg`, релиз содержит:

- `ytm-alice-0.7.0-linux-arm64` — основной сервис, статический Linux ARM64.
- `ytm-alice-player-0.7.0-linux-armhf` — плеер ARMhf, использующий библиотеки прошивки.
- `bt-proxy-0.7.0-linux-armv7-musl` — медиасервис, статический ARMv7 musl.

Все три файла включены в `SHA256SUMS`. После скачивания проверьте суммы,
переименуйте файлы в `ytm-alice`, `ytm-alice-player` и `bt-proxy` и выдайте им
права на запуск (`chmod +x`). Архитектура в имени не гарантирует поддержку
конкретной модели колонки.

Эти файлы предназначены для ручного развёртывания и диагностики. Они не заменяют
полную установку: нужны также `alice-media`, `bus.conf`, библиотеки прошивки и
настройка медиаслоя, описанная в [MEDIA.md](MEDIA.md). Для обычной установки
используйте `.yampkg`, который включает все компоненты и лицензии.
